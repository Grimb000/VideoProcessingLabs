# Лабораторная работа №2
## Анализ движения объектов

### Описание проекта
Данное приложение реализует основные методы анализа движения объектов в видеопотоке в рамках лабораторной работы №2.

В программе объединены три части задания:
- **Детекция объектов** с помощью нейронной сети **YOLOv8**.
- **Отслеживание объектов** с помощью трекера **CSRT**.
- **Построение оптического потока** методом **Фарнебека**.

Также реализован удобный оконный интерфейс с возможностью:
- загрузки видеофайла;
- воспроизведения и паузы;
- переключения режимов обработки;
- просмотра результата в реальном времени;
- сохранения обработанного видео;
- вызова краткой справки по реализованным методам.

---

## Цель работы
Освоить базовые методы детекции и отслеживания объектов в видеопотоке, а также методы анализа движения на основе траекторий и оптического потока.

---

## Реализованные методы

### 1. Детекция объектов — YOLO
В первой части лабораторной работы реализована модель **YOLOv8n** из библиотеки `ultralytics`.

Принцип работы:
- нейронная сеть анализирует каждый кадр видео;
- обнаруживает объекты различных классов;
- отображает ограничивающие рамки вокруг найденных объектов.

Результат: на обработанном видео показываются найденные объекты с рамками и подписями.

### 2. Отслеживание объектов — CSRT
Во второй части реализован алгоритм трекинга **CSRT** (*Channel and Spatial Reliability Tracker*).

Принцип работы:
- пользователь вручную выделяет объект на кадре;
- после подтверждения выбор передаётся трекеру;
- алгоритм отслеживает положение объекта на следующих кадрах.

Если объект теряется, на экране выводится сообщение **Lost Track**.

### 3. Оптический поток — метод Фарнебека
В третьей части реализован плотный оптический поток методом **Фарнебека**.

Принцип работы:
- вычисляется движение пикселей между двумя соседними кадрами;
- строится тепловая карта движения;
- отображается векторное поле в виде стрелок.

Интерпретация результата:
- **цвет** показывает направление движения;
- **яркость** показывает интенсивность (скорость) движения.

## Функциональные возможности программы
Программа поддерживает следующие режимы и функции:

- **Orig** — отображение исходного видео без обработки;
- **YOLO** — детекция объектов на видео;
- **CSRT** — ручной выбор и отслеживание объекта;
- **Flow** — визуализация оптического потока методом Фарнебека;
- **REC** — включение и остановка записи результата в файл;
- **Help** — отображение справки по методам;
- **PAUSE / RESUME** — пауза и продолжение воспроизведения;
- **Open** — открытие нового видеофайла.

Дополнительно реализованы:
- полоса прокрутки (scrubber) для перемещения по видео;
- отображение текущего кадра, FPS и активного режима;
- воспроизведение аудио при наличии библиотеки `ffpyplayer`.

---

## Используемые библиотеки
Для работы программы используются следующие библиотеки Python:

- `opencv-python` (`cv2`) — обработка видео, интерфейс окна, трекинг, оптический поток;
- `numpy` — работа с массивами и вычисления;
- `ultralytics` — загрузка и использование модели YOLOv8;
- `ffpyplayer` — воспроизведение аудиодорожки видео;
- `tkinter` — вывод окна справки.

Перед запуском необходимо установить зависимости:

## Работа с программой
### Загрузка видео
После старта программа предлагает выбрать видеофайл. Для macOS и Windows используется системный диалог выбора файла, в остальных случаях путь можно ввести вручную.

### Режим YOLO
После нажатия кнопки **YOLO** видео обрабатывается нейросетевой моделью, а на кадрах отображаются найденные объекты.

### Режим CSRT
1. Нажать кнопку **CSRT**.
2. В появившемся окне выделить объект мышью.
3. Нажать **SPACE** или **ENTER**.
4. После этого начнётся отслеживание объекта.

### Режим Flow
После выбора режима **Flow** программа строит оптический поток между соседними кадрами и показывает тепловую карту вместе со стрелками движения.

### Сохранение результата
Кнопка **REC** запускает или завершает запись обработанного видео. Результат сохраняется в файл `output_result.mp4`.

---

## Особенности реализации
- При отсутствии библиотеки `ultralytics` программа продолжит работу, но режим YOLO будет недоступен.
- При отсутствии `ffpyplayer` программа будет работать без звука.
- Для CSRT предусмотрена совместимость с разными версиями OpenCV: используется `cv2.TrackerCSRT_create()` или `cv2.legacy.TrackerCSRT_create()`.
- При достижении конца видео воспроизведение начинается заново.
