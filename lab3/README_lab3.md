# Лабораторная работа №3
## Семантический и сценовый анализ видеопотока

### Цель работы
Изучить методы семантической сегментации видеопотока, а также базовые подходы к анализу сцены и контекста на основе подсчета объектов.

### Вариант
Часть 1 — DeepLab (семантическая сегментация)  
Часть 2 — Подсчёт объектов некоторого класса

### Описание программы
В рамках лабораторной работы реализовано оконное приложение для обработки видео.

Программа позволяет:
- загружать видеофайл;
- воспроизводить исходное видео;
- применять модель семантической сегментации DeepLab;
- выполнять сценовый анализ через подсчёт объектов класса person;
- сохранять результат обработки в видеофайл;
- выводить краткую справку по реализованным методам.

### Реализованные методы

#### 1. Семантическая сегментация
Для семантической сегментации используется модель `DeepLabV3_MobileNet_V3_Large` из библиотеки `torchvision`.

Принцип работы:
- каждый пиксель изображения классифицируется нейронной сетью;
- для каждого класса формируется маска;
- маска накладывается на исходный кадр в виде полупрозрачного цветного слоя.

Результат:
- на видео отображается сегментация сцены по классам объектов.

#### 2. Сценовый анализ
Для сценового анализа используется модель `YOLOv8` в режиме трекинга.

Принцип работы:
- модель обнаруживает объекты класса `person`;
- каждому найденному человеку присваивается уникальный идентификатор;
- программа выполняет накопительный подсчёт всех уникальных людей, появившихся в кадре.

Результат:
- на видео отображаются рамки вокруг людей;
- в левом верхнем углу показывается текущее количество найденных людей.

### Используемые библиотеки
Для работы программы используются:
- `opencv-python`
- `numpy`
- `torch`
- `torchvision`
- `ultralytics`
- `tkinter`

### Установка зависимостей
Установить зависимости можно командой:

```bash
pip install opencv-python numpy torch torchvision ultralytics
```

### Запуск программы
Запуск осуществляется командой:

```bash
python lab3.py
```

### Управление
После запуска программы открывается окно приложения с кнопками управления:

- `Load` — загрузка видеофайла;
- `Orig` — показ исходного видео;
- `DeepLab` — запуск семантической сегментации;
- `Count` — запуск подсчёта людей;
- `Save` — начало и остановка записи результата в файл `output_lab3.mp4`;
- `Help` — краткая справка по методам.

Для выхода из программы используется клавиша:

```text
q
```

### Входные данные
В качестве входных данных используются видеофайлы форматов:
- `.mp4`
- `.avi`
- `.mkv`
- `.mov`

### Выходные данные
В результате работы программы формируется:
- отображение исходного или обработанного видео;
- видеофайл `output_lab3.mp4` при сохранении результата.

### Особенности работы
- Для режима `DeepLab` используется предобученная модель семантической сегментации.
- Для режима `Count` выполняется подсчёт только объектов класса `person`.
- При первом запуске модели могут автоматически загружаться из интернета.
- При окончании видео воспроизведение начинается сначала.
