# Лабораторная работа №4
## Системы дополненной реальности на основе видеопотока

### Цель работы
Ознакомиться с принципами дополненной реальности и реализовать простейшую AR-систему с использованием видеопотока и методов компьютерного зрения.

### Условие лабораторной работы
В рамках работы необходимо реализовать оконное приложение, которое выполняет:
- загрузку видео;
- воспроизведение исходного видео;
- применение реализованного метода к видеопотоку;
- отображение результата обработки;
- сохранение результата;
- вывод краткой справки.

Лабораторная работа состоит из двух частей:
1. Распознавание ArUco-маркеров.
2. Оценка положения и ориентации маркера в пространстве.

---

## Описание программы
В данной лабораторной работе разработано оконное приложение на Python с использованием OpenCV.

Программа позволяет:
- загружать видеофайл;
- просматривать исходное видео;
- распознавать ArUco-маркеры в кадре;
- отображать границы маркеров и их ID;
- вычислять положение маркеров относительно камеры;
- отображать оси координат для каждого найденного маркера;
- сохранять результат обработки в видеофайл.

---

## Реализованные части

### Часть 1. Распознавание маркеров
В программе реализовано обнаружение ArUco-маркеров в видеопотоке.

Используется словарь:
- `DICT_6X6_250`

Для каждого найденного маркера программа:
- определяет его границы;
- отображает контур маркера;
- подписывает его идентификатор `ID`.

Таким образом выполняется первая часть задания: распознавание маркеров, отображение их границ и ID. [page:94]

### Часть 2. Оценка позиции маркера
После обнаружения маркера вычисляется его положение и ориентация в пространстве относительно камеры. Для этого используются координаты четырёх углов маркера и процедура оценки позы на основе решения задачи PnP. OpenCV указывает, что такая оценка строится через соответствие 2D-углов маркера и его 3D-координат, а результат задаётся векторами поворота и переноса. [page:94]

Результат визуализируется с помощью координатных осей:
- ось **X** — красная;
- ось **Y** — зелёная;
- ось **Z** — синяя.

Отрисовка осей координат полностью соответствует второй части задания. [page:94]

## Используемые технологии
В программе используются следующие библиотеки:
- `opencv-contrib-python`
- `numpy`
- `tkinter`

Почему нужен именно `opencv-contrib-python`: модуль `cv2.aruco` входит в состав contrib-сборки OpenCV, а не в базовый пакет `opencv-python`. [page:94]

## Установка зависимостей

Если ранее был установлен обычный OpenCV, рекомендуется удалить его:

```bash
pip uninstall opencv-python
```

Затем установить необходимые библиотеки:

```bash
pip install opencv-contrib-python numpy
```

Если `tkinter` отсутствует, его установка зависит от операционной системы:
- на Windows обычно входит в Python по умолчанию;
- на macOS чаще всего также уже установлен;
- на Linux может понадобиться отдельная установка через пакетный менеджер.

## Как проверить работу программы
Для тестирования необходимо использовать видео, на котором присутствует ArUco-маркер из словаря `DICT_6X6_250`. OpenCV рекомендует использовать корректно сгенерированные маркеры выбранного словаря, потому что ID маркера — это индекс внутри словаря, а детектор ищет именно коды из конкретного набора. [page:94]

Порядок проверки:
1. Запустить программу.
2. Загрузить видео с маркером.
3. Нажать кнопку `ArUco` — должны появиться границы маркера и его ID.
4. Нажать кнопку `Pose` — должны появиться оси координат.
5. При необходимости нажать `Save` для сохранения результата.

## Теоретическая основа

### Что такое ArUco-маркеры
ArUco-маркеры — это квадратные бинарные маркеры с толстой чёрной границей и внутренней матрицей битов, которая задаёт идентификатор маркера. Чёрная рамка облегчает обнаружение, а внутренняя кодировка позволяет определить ID и применять исправление ошибок. [page:94]

### Что такое оценка позы маркера
Оценка позы — это определение положения и ориентации объекта в пространстве относительно камеры. Для маркера это делается по четырём его углам: известны 3D-координаты углов на плоскости маркера и их 2D-проекции на изображении, после чего вычисляются векторы поворота и переноса. [page:94]

### Как интерпретируются оси
После оценки позы на маркере рисуется локальная система координат:
- красная ось показывает направление X;
- зелёная ось показывает направление Y;
- синяя ось показывает направление Z, выходящую из плоскости маркера. [page:94]
